# Gustavo Dantas — Holographic Developer Portfolio

Portfólio pessoal com estética futurista inspirada em interfaces holográficas de ficção científica. Construído com HTML, CSS e JavaScript puro, sem frameworks ou processo de compilação.

## ✨ Recursos

- Núcleo holográfico com anéis animados e indicadores HUD
- Fundo com partículas conectadas por linhas
- Efeito de texto digitado
- Layout responsivo para desktop e dispositivos móveis
- Seções de perfil, tecnologias, projetos e contato
- Respeito à preferência de movimento reduzido do sistema

## 🚀 Publicar com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço exibido nessa página.

## 🛠️ Personalização

- Edite o texto e os links em `index.html`.
- Ajuste cores, tipografia e layout em `style.css`.
- Ajuste partículas, frases animadas e menu em `script.js`.

## 🔐 Antes de publicar

Não inclua chaves de API, tokens, senhas, arquivos `.env` ou dados pessoais de terceiros. Confira também se todos os links de contato apontam para seus perfis reais.
